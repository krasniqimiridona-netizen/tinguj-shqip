# 📘 Fito Online: e-book në shqip

Udhëzues praktik (31 faqe, A5, PDF) me 12 mënyra reale për të fituar para online, shabllone mesazhesh, plan 30-ditor dhe si të shmangësh mashtrimet.

| Skedari | Çfarë është |
|---------|-------------|
| `Fito_Online.pdf` | Libri gati për shitje |
| `kopertina.png` | Kopertina për faqen e shitjes dhe për Instagram |
| `fito-online.html` | Burimi: ndrysho tekstin këtu |
| `Earn_Online.pdf` | Versioni në anglisht (31 faqe) |
| `cover-en.png` | Kopertina e versionit anglisht |
| `earn-online.html` | Burimi i versionit anglisht |

## Ta ndryshosh dhe ta rikrijosh PDF-në

Ndrysho `fito-online.html` (p.sh. emrin e autorit "Shqiponja Digital"), pastaj:

```bash
chromium --headless=new --no-pdf-header-footer --print-to-pdf=ebook/Fito_Online.pdf ebook/fito-online.html
```

## Si ta shesësh

1. Krijo llogari në **Gumroad** ose **Payhip**. Kontrollo te "Payouts" që mund t'i tërheqësh paratë nga vendi yt.
2. Ngarko `Fito_Online.pdf` dhe vendos `kopertina.png` si kopertinë.
3. Çmimi: 7–9€. Ofertë lansimi: -50% për 48 orët e para.
4. Vendos linkun në bio të Instagramit dhe bëj Reels me këshilla nga libri.
